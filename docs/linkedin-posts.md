## How to maintain

1. When you publish a LinkedIn or Medium post tied to this repo, add a row here **in the same PR** that ships or documents the feature.
2. Link the same URL from the root [README](../README.md) **LinkedIn catalog** — not from NuGet `PACKAGE_README.md` or packed XML docs.
3. Prefer activity permalinks (`urn:li:activity:…`) or `/posts/…` URLs — do not invent links.
4. New packable BuildingBlock: add `AGENTS.md` + `PACKAGE_README.md` (no LinkedIn URLs in those files).
